# ADR 0003: License the repository and all skills under MIT

- Status: Accepted
- Date: 2026-09-24

The user chose one license for the entire skill collection. Apply the standard MIT License to all repository-authored materials, keep the canonical full text in the root `LICENSE`, and include identical `LICENSE` copies plus `license: MIT` frontmatter in every independently installable skill so each copied package retains the license notice. Keep the repository private until separately made public; license choice does not change remote visibility. Use SPDX identifier `MIT`.
